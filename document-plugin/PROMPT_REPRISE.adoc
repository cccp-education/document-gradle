== Pièges Gradle à retenir (S-232)

1. `task.htmlFile.set(producer.outputFile)` crée une dépendance implicite → le producer s'exécute
   même quand la tâche est lancée seule. Snapshot de valeur à la configuration ou chemin statique.
2. `.get()` sur un provider mappé d'une tâche non terminée → `Querying the mapped value ... is not
   supported` (configuration-time). Résoudre depuis `project.layout` plutôt.
3. `@InputFile @Optional` non-null valide l'existence du fichier AVANT l'action → `Input file does
   not exist`. Pour un fichier optionnel produit par une autre tâche : `@Input @Optional String`.
