== Vision (GBL-010)

La traduction d'un site est un **arbre à deux branches** ; document possède la
**branche Data** : chaque article EST un document, chaque document a l'**arbre du
document AsciiDoc (AST)** dedans. document **extrait** le pivot, **traduit la
prose**, et pour la balise `[plantuml,…]` (feuille spéciale) **délègue** au port N0
`PlantUmlTranslationPort` — il ne réimplémente jamais la logique PlantUML. Il
expose, par nœud de l'AST, un **statut** (`MISSING`/`PENDING`/`TRANSLATED`/`BROKEN`).
Cadrage racine : `CADRAGE_EPIC_GBL_010_ARBRE_TRADUCTION_SITE.adoc`.
