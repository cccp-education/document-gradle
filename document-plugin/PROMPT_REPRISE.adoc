== Politique de matter (DOC-BOOK-MATTER, S-261)

- `matterPolicy` (défaut `DERIVED`) : les racines de matter sont dérivées de la
  TOC, un livre n'exige un FRONT/BACK que si sa TOC le déclare → le faux
  positif permanent de la règle S3 sur une TOC body-only (racines `{1..4}` du
  corpus FPA) est **supprimé**.
- `matterBreaks` (défaut `false`) : `<<<` aux transitions de matter + page de
  titre fermée — opt-in.
- DSL `book { matterPolicy.set(MatterPolicyMode.LEGACY); matterBreaks.set(true) }`
  + CLI `-Pdocument.bookMatterPolicy` / `-Pdocument.bookMatterBreaks`.
- Preuve dogfooding S-261 : DERIVED → 0 finding matter ; LEGACY → 2 (faux
  positif historique prouvé).
