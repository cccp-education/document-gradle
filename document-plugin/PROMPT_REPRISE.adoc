== Anti-glue Cucumber (règle de propriété — S-238)

Chaque feature a UN runner propriétaire. Le runner global (glue
`document.scenarios`) ne découvre que `document.feature` +
`release-notes.feature` + `frontmatter_retranslate.feature`. Toute
nouvelle feature doit soit rejoindre un runner dédié (pattern : runner +
glue + tag + CucumberTaskSpec dans build.gradle.kts), soit explicitement
rejoindre le global avec ses steps dans `document.scenarios`.
Le 19e runner dédié est `ocrQualityCucumberTest` (S-251).
