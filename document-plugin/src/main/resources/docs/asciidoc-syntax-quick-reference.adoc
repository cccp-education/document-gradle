= AsciiDoc Syntax Quick Reference

== Paragraphs

Paragraphs don't require special markup in AsciiDoc.
A paragraph is defined by one or more consecutive lines of text.
Line breaks within a paragraph are not displayed.

Leave at least one empty line to begin a new paragraph.

== Text Formatting

Constrained bold: *bold*
Unconstrained bold: **b**old
Constrained italic: _italic_
Unconstrained italic: __i__talic
Constrained monospace: `monospace`
Unconstrained monospace: ``m``onospace
Literal monospace: `+http://localhost:8080+` or `+/issue/{id}+`
Mixed: `*_bold italic monospace_*`

Highlight: #text#
Custom role: [.myrole]#text#
Superscript: ^super^script
Subscript: ~sub~script

== Source Code Blocks

Source block with syntax highlighting:
[source,ruby]
----
require 'sinatra'
get '/hi' do
  "Hello World!"
end
----

Implied source block (language alone):
[,ruby]
----
require 'sinatra'
----

Listing block (no highlighting):
----
GEM
  remote: https://rubygems.org/
  specs:
    asciidoctor (2.0.15)
----

Literal block:
....
error: 1954 Forbidden search
Would you like to try again? y/n
....

Source block with callouts:
[source,ruby]
----
require 'sinatra' // <1>
get '/hi' do // <2>
  "Hello World!" // <3>
end
----
<1> Library import
<2> URL mapping
<3> HTTP response body
