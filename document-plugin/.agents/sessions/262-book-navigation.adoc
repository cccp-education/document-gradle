== Mission

Reprise sur demande pilote. Le dernier item actionnable sans coût externe
désigné par l'INDEX/BACKLOG est la dette `DOC-BOOK-CONSISTENCY-B6`, issue de la
code review S-258 (anomalie B6) :

- `BookNumbering.numbers()` retourne le `ref` lui-même (dérivation identité) ;
- `BookNavigation` (prev/next) est exposé mais **aucun consommateur prod** ne
  l'utilise.

L'US demandait de trancher : soit une vraie numérotation indexée, soit
**documenter** la dérivation identité comme le choix assumé ; et brancher
`BookNavigation` dans `BookLayout` (liens prev/next) **ou le retirer**.

Méthode : baby-step DDD/TDD/BDD strict (UT domaine pur → FT TestKit → BDD
runner dédié), puis dogfooding réel sur le corpus FPA.

== Décisions

. *Numérotation identité = choix assumé, documenté.* Le numéro imprimé dans le
   livre est celui déjà imprimé dans la TOC source (`1.0.2.6.4`) ; recalculer un
   index 1-based par frères **divergerait** du livre physique que tient le
   lecteur. Le KDoc de `BookNumbering.numbers()` documente désormais ce choix
   (plus de lecture « stub inachevé »).
. *Navigation branchée en prod* — l'alternative « retirer » est écartée : la
   navigation est le chaînon manquant qui rend le livre **auto-navigable**
   (liens `<<ref,title>>` en pied de section). Opt-in (`emitNavigation`,
   défaut `false`) pour une backward compat totale.
. *Bug latent corrigé* : la navigation courait sur les *pages OCR*
   (`BookTree.leaves`), pas sur les sections *émises*. Une ligne TOC multi-pages
   (`| 1.0.1 | … | 5, 6, 7, 8 | …`) produit plusieurs `BookSection` de même
   `ref` → le lien « suivant » pointait sur la **même** section logique. La
   navigation court désormais sur `BookNumbering.emittedNodes(tree)` (refs
   distincts, ordre document) → le lien « suivant » est toujours une section
   *distincte*.

== Implémentation (3 couches, TDD/BDD strict)

=== Domaine pur (UT)

- `BookNumbering.emittedNodes(tree)` : sections distinctes en ordre document
  (une par `ref`, première page gagne).
- `BookNumbering.navigation(tree, ref)` : prev/next sur les sections *émises*
  (fix bug latent multi-pages).
- `BookNumbering.numbers()` : KDoc documentant la dérivation identité assumée.
- `BookLayout.emitNavigation` (défaut `false`) + `BookLayout.navigationLinks(nav)`
  : émet `<<ref,title>>` par voisin présent, `" | "`-joint, vide si standalone.

=== Assemblage (UT)

- `BookAssembler.buildStructuredBody` : quand `layout.emitNavigation`, appende
  la ligne de navigation au pied du bloc de chaque section (après le contenu).

=== Wiring Gradle (FT)

- `AssembleBookTask.navigation: Property<Boolean>` (défaut `false`) → injecté
  dans les deux `BookLayout` (base + imagesDir).
- `BookDsl.navigation` + `DocumentExtension.bookNavigation` (mirror) +
  convention plugin.
- CLI `-Pdocument.bookNavigation=true` + DSL
  `book { navigation.set(true) }`.
- Contrat N3 : `BookConfig.navigation` + `DocumentConfigSerializer` (write/read)
  + `SerializeDocumentConfigTask.bookNavigation`.
