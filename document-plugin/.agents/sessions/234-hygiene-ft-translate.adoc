== Pièges à retenir

1. Une `Property` DSL sans `convention(...)` reste *unset même après
   `.orElse(...)` en amont* : `cliProp(...).orElse(ext.x)` produit un
   provider unset si aucune des deux branches n'a de valeur → erreur
   configuration `Value not set` à l'exécution de la tâche.
2. Le message Gradle « Possible solutions: 1. Assign a value to 'X'.
   2. Mark property 'X' as optional » pointe la tâche, pas la racine —
   remonter la chaîne de providers jusqu'à l'extension DSL.
3. Le moteur Cucumber *global* (runner glue `document.scenarios`) n'est
   pas une gate : les steps des runners dédiés (ex. `document.bookvalidation`)
   sont invisibles pour lui → `UndefinedStepException`. Comparer les
   baseline avant/après (stash) pour isoler l'impact d'un fix.
