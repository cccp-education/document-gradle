== Découvertes / pièges

* *Le catalogue N0 est la source de vérité* — aucun catalogue local à créer ;
  `LanguageCatalog.ALL` porte les 22 langues (+ 3 RTL `ar`/`ur`/`fa`). Le
  split-brain est évité par construction (D2).
* *Le moteur mono-langue était dupliquable* — sans l'extraction
  `BookTranslationRunner`, la nouvelle tâche aurait recopié la chaîne
  translate→assemble→materialise→write. L'extraction prouve la non-régression
  par les tests existants (`TranslateBookTaskUnitTest` vert).
* *`@OutputFiles` pour un fan-out dynamique* — un `@OutputDirectory` aurait
  revendiqué le répertoire partagé `docs/document/` (conflit de tâches) ; la
  collection `@OutputFiles` peuplée par un provider reflète le plan exact.
* *Suffixe fake par langue cible* — le fake mono-langue suffixe la cible ; le
  multi doit suffixer **chaque** cible, sinon tous les livres seraient
  identiques (bug attrapé par la conception du factory).
