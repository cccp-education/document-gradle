== Découverte P0 — `kotlin-stdlib-jdk8` muet

Central rejetait la publication : `Dependency version information is missing for
dependency: org.jetbrains.kotlin:kotlin-stdlib-jdk8`.

* Cause : le BOM ne contraignait pas `kotlin-stdlib-jdk8`, consommé sans version
  par `implementation(kotlin("stdlib-jdk8"))`.
* Question pilote utile (« est-ce indispensable sous JDK 25 ? ») : **non** —
  l'artefact `-jdk8` est un **shim vide de 953 octets** (0 classe hors
  `module-info.class`) depuis Kotlin 1.8, les extensions JDK7/8 étant fusionnées
  dans `kotlin-stdlib`.
* Correctif : **retrait** de `kotlin("stdlib-jdk8")` (le `kotlin-stdlib`
  transitif, épinglé par le BOM, suffit). Le BOM 0.0.65 épingle malgré tout
  l'alias toml par cohérence de famille.
* Le BOM fraîchement publié doit être **propagé** (repo1 HTTP 200) avant de
  publier un plugin qui importe ses contraintes (1er essai sous 0.0.64 → 404).
