== US-3 — BookAssembler structuré (émission niveaux, titre, toc, ancres)

*Production* (1 fichier modifié, DDD pur) :
- `BookAssembler.kt` — ajout de l'overload `assemble(tree, layout, title, author, resolveContent: (BookSection)->String): BookAssemblyResult`, helper `pageContentResolver(pagesDir)`, et `buildStructuredBody(tree, layout, title, author, resolveContent)`.
  - Émet uniquement nœuds réels (`source != null`).
  - Ancre `[[ref]]` avant le heading.
  - Heading level = `node.level + 1` (ref `1` → `==`, ref `1.1` → `===`).
  - Page break entre nœuds de niveau 0 (`node.level == 0`).
  - Titre page (`= title`) + TOC (`:toc:`) selon `BookLayout`.
  - Corps structuré DFS : titre du nœud + récursivité enfants.
  - Retour `BookAssemblyResult(content, pages=emptyList(), photoCount=0)` pour préserver signature non-régression.

*Tests* `BookAssemblerStructuredTest.kt` — 10 UT couvrant :
  - Titre page présent/absent selon `emitTitlePage`.
  - TOC présent/absent selon `emitToc`.
  - Niveaux de heading `==`/`===` pour refs à 1/2 segments.
  - Ancres `[[ref]]` émises avant chaque heading.
  - Ordre front/matter → body → back respecté.
  - Injection de contenu via `resolveContent`.
  - Page break entre sections de niveau 0.
  - Multi-page sections (chunks avec même `ref`) concaténés.
  - Absence de titre page → pas de `= title` ligne.

*Correctifs* :

== US-4 — BookNumbering (10 UT TDD strict)

*Production* (2 fichiers neufs, DDD pur) :
- `BookNumbering.kt` — objet avec :
  - `numbers(tree): Map<BookSection, List<String>>` : ref→liste de numéros (ref lui-même).
  - `number(tree, ref): String` : le `ref` lui-même (FPA TOC convention).
  - `anchor(ref): String` : `[[ref]]`.
  - `navigation(tree, ref): BookNavigation` : `previous`/`next` siblings in preorder (ou `null`).
- `BookNavigation.kt` — data class immuable (`previous: BookSection?`, `next: BookSection?`).

*Tests* `BookNumberingTest.kt` — 10 UT :
  - `numbers(tree)` renvoie ref→ref pour chaque nœud réel.
  - `number(tree, ref)` = ref (pas de numérotation positionnelle qui renumérote racines matter).
  - `anchor(ref)` = `[[ref]]`.
  - `navigation` : premier nœud → `previous=null`, dernier → `next=null`.
  - Orphelins matter synthétiques (`0.x`, `9.x`) gardent leur ref comme numéro.
  - Ordre preorder respected.
  - Arbre vide → maps vides.
  - Référence absente → `number` lève `IllegalArgumentException`.
  - `navigation` sur racine → `previous=null`, `next=` premier enfant ou `null`.

*Décision de conception* : rejet de la numérotation positionnelle (qui aurait transformé `== 0. Front Matter` en `== 2. Front Matter` après ajout de matter racine synthétique `9`) → adoption ref-based (numero = ref).

*Méthodologie* : baby-step TDD strict RED → GREEN → REFACTOR sur chaque fonction.
