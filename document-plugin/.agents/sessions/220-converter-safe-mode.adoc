== Objectif

Implémenter une garde `safeMode` DSL configurable dans `DocumentConverter` pour maîtriser la sécurité des conversions AsciidoctorJ, en baby-step DDD/TDD/BDD strict. Ajouter :
- Un `Property<SafeMode>` exposés via le DSL imbriqué `converter { }` sur `DocumentExtension`.
- Un miroir flat `safeMode` + flag CLI `-Pdocument.safeMode`.
- Propagation de la valeur vers `ConvertDocumentTask` puis `DocumentConverter.buildOptions`.
- Default `UNSAFE` pour backward-compat.
Tests : unit (buildOptions), fonctionnel (GradleTestKit), Cucumber (scénarios DSL/CLI).
Autorisation : commit + push à la clôture.

== Travail effectué

=== Implémentation production (DDD baby-step) ===

1. **DocumentConverter.kt** :
   - Rendu `buildOptions` **internal** avec param `safeMode: SafeMode = SafeMode.UNSAFE` (utilise `OptionsBuilder.safe(safeMode)`).
   - Méthodes `convert`, `convertToFile`, `convertToHtml`, `convertToPdf`, `convertToEpub`, `convertToDocBook`, `convertToManPage` exposent `safeMode` (défaut UNSAFE).
   - Appels vers `buildOptions(safeMode)`.

2. **ConverterDsl.kt** (NOUVEAU) :
   - `class ConverterDsl(val safeMode: Property<SafeMode>)` — DSL imbriqué standard.

3. **DocumentExtension.kt** :
   - `abstract val safeMode: Property<SafeMode>`.
   - `lateinit var converter: ConverterDsl`.
   - `initNested(..., converter)`.
   - `fun converter(action: Action<ConverterDsl>)`.
   - Miroir flat : `ext.safeMode.convention(ext.converter.safeMode)`.

4. **ConvertDocumentTask.kt** :
   - `abstract val safeMode: Property<SafeMode>`.
   - Passé à tous les appels `DocumentConverter.*`.

5. **DocumentPlugin.kt** :
   - Wiring du bloc DSL : `converter = ConverterDsl(safeMode = project.objects.property(SafeMode::class.java))` dans `initNested`.
   - Conventions : `ext.converter.safeMode.convention(SafeMode.UNSAFE)` + `ext.safeMode.convention(SafeMode.UNSAFE)`.
   - Miroir : `ext.safeMode.convention(ext.converter.safeMode)`.
   - CLI : `task.safeMode.set(cliProp(project, "safeMode").map { SafeMode.valueOf(it.uppercase()) }.orElse(ext.safeMode))`.
   - Import `org.asciidoctor.SafeMode`.

== Décisions

- **Default UNSAFE** : backward-compat total (comportement identique si aucune config).
- **Propagation** : le `safeMode` du DSL/CLI atteint chaque backend (`buildOptions` interne) via `ConvertDocumentTask`.
- **DDD** : `ConverterDsl` (nested block) + miroir flat + propriété abstraite sur l'extension.
- **Baby-step** : chaque ajout compilé, testé unitairement puis fonctionnellement puis BDD.
- **Sécurité** : en mode `SERVER`/`SECURE`, l'include de fichiers système et l'exécution de macros sont restreints (selon AsciidoctorJ).
