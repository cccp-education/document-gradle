== Objectif

Créer le modèle de données `Table` POJO pour la validation syntaxique des tableaux

== Livrables

=== Table.kt — Modèle DDD
- `Table(cols, header, body)` / `Row(cells)` / `Cell(inline, colSpan, rowSpan, halign, valign)`
- `ColSpec(width, halign, valign)` + `HAlign`/`VAlign` enums
- `extractTranslatable()` → `List<TranslatableSegment>` (texte seul, positions)
- `reinject(translations)` → `Table` (réinjecte sans toucher au formatage)
- `toAsciiDoc()` / `toHtml()` (round-trip + validation bakery)

=== AsciiDocParser.parseTableStructured()
- `\|` (échappement pipe), `a|`/`h|` (style cellule)
- `2+|`/`.3+|` (spans), `<|`/`^|`/`>|` (alignement horizontal)
- `.<|`/`.^|`/`.>|` (alignement vertical)
- `[cols="<1,^2,>3"]` → `List<ColSpec>` avec width + halign
- `parseColSpecs()` / `parseSingleColSpec()` / `parseCellPrefix()` / `splitStructuredCells()`
