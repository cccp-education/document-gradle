== Baby steps

=== MASS-1 — BlockChecksum + BlockDelta (DDD pur)

- `document/translation/delta/BlockChecksum.kt` :
  - `BlockTranslationStatus` enum (`TRANSLATED`, `PENDING`)
  - `BlockChecksumEntry(hash, status)` — `parse("hash:STATUS")` + `serialize()`,
    format legacy `"hash"` seul → `PENDING` (rétro-compatible)
  - `BlockChecksum.sha256(block)` SHA-256 + `computeForBlocks(blocks)` → `Map<idx, hash>`
    (heading, paragraph, list, table, admonition, source, descriptionList ;
    `Hr`/`BlockMacro` non-checksummés)
- `document/translation/delta/BlockDelta.kt` :
  - `BlockDelta(modifiedBlocks, preservedBlocks)` + `isEmpty()`
  - `compute(previous: Map<String,BlockChecksumEntry>, current: Map<String,String>)` —
    modifié si absent / hash différent / statut ≠ `TRANSLATED`, sinon préservé.
- Tests : `BlockDeltaTest` 26 UT (block unchanged/modified, diagram preserved,
  statut PENDING re-traduit, format legacy, sérialisation round-trip).

=== MASS-2 — câblage traducteur

- `DocumentTranslator.translateArticleWithDelta(sourceArticle, previousTranslated, delta, ...)`
  (internal→public) : préserve les blocs indexés dans `delta.preservedBlocks`
  (depuis `previousTranslated`), re-traduit les blocs modifiés. Dispatch table/plantuml
  par index original (`tableIndexByOriginalIndex`/`plantUmlIndexByOriginalIndex`).
  `delta.isEmpty()` → retourne `previousTranslated` (Economie d'Encre).
- `ContentTranslationService.translateSingleFileWithBlockDelta(sourceFile, targetFile,
  previousBlockChecksums, srcLang, tgtLang): Map<String,BlockChecksumEntry>` (public) :
  fresh path si previous vide / target absent — delta path sinon (parse target →
  `BlockDelta.compute` → re-traduit modifiés, préserve traduits). Écrit `targetFile`.
- Tests : `DocumentTranslatorBlockDeltaTest` 4 UT, `BlockDeltaWireDebugTest` 1.
