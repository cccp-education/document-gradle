== Pièges / notes

* *Un premier rang de tableau n'est un en-tête que si `options="header"` est
  déclaré* — l'adapter lit `Table.getHeader()`, il ne devine pas par position.
  Toutes les fixtures de test déclarent l'option explicitement.
* *Deux modèles tabulaires parallèles* (piège #47) : l'AST
  `org.asciidoctor.ast.Table` (lifting) et le pivot regex
  `document.translation.Table` (traduction) cohabitent — nommage sans ambiguïté,
  aucune tentative d'unification.
* *Contrainte OSS* : aucun rôle métier codé dans le plugin (schéma injecté,
  D4) — c'est le cœur de la conception et la protection de la gate RENAME.
