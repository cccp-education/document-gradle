== Décisions

. *EPIC test-only* — zéro code de production modifié. Le pont filesystem
  fonctionne ; la valeur est la *garantie contractuelle fidèle*.
. *Fidélité producteur* — les fixtures reproduisent la sortie codex réelle :
  pages `.adoc` **sans en-tête**, contenu OCR brut.
. *Chemin de production couvert* — scénario `TOC → BookTocParser →
  BookTreeBuilder → assemble(tree, contentAwareResolver)`, exactement le
  chemin de `AssembleBookTask`.
. *Section multi-pages* — une ligne TOC `Page = 1, 2` + `001-*.adoc,
  002-*.adoc` → **un** en-tête (section logique), **deux** contenus ordonnés.
. *Assertions sur le contrat, jamais sur la fixture* — un en-tête doit être
  prouvé *dérivé de la TOC*.
. *Runner/steps/feature conservés* — pas de nouvelle feature ni de nouveau
  runner (économie d'encre). Tag `@cross-borough @book-pipeline`, tâche
  `crossBoroughCucumberTest`.
