= Session 224 — DOC-XREF-VALIDATE (Validation références croisées AsciiDoc)

:date: 2026-08-30
:borough: document-gradle (New Orleans 🟢)
:epic: DOC-XREF-VALIDATE

== Résumé

EPIC produit DOC-XREF-VALIDATE ✅ TERMINÉ (4/4 US). Validation des références croisées
AsciiDoc (`<<id>>` / `xref:id[]`) avant publication du livre — complète la solidité
documentaire après DOC-CR3-2 (safeMode), DOC-CR4 (includeGuard), DOC-CR5 (security policy).

== Livrables (DDD pur `document.xref`)

- `XrefValidationMode.kt` — enum OFF/STRICT/LENIENT.
- `XrefValidationResult.kt` — sealed Valid/Invalid (liste des refs manquantes).
- `XrefValidator.kt` — `extractAnchors` / `extractReferences` / `validate` (regex sur texte brut,
  ancres `[[id]]`/`[[id,label]]`/`[#id]`, références `<<id>>`/`<<id,text>>`/`xref:id[]`/`xref:id[text]`,
  IDs `[A-Za-z0-9_][A-Za-z0-9_.-]*`, auto-IDs implicites hors périmètre).
- `XrefValidationReport.kt` — entry + liste, `toJson()` / `fromResult()` (rapport
  `build/docs/document/xref-validation-report.json`).

== Câblage

- `ConvertDocumentTask` : valide le texte source avant conversion, sévérité
  (STRICT → `GradleException` fail-fast citant les refs manquantes ; LENIENT → `logger.warn`
  + rapport ; OFF → no-op, défaut backward-compat).
- `ConverterDsl.kt` : `+xrefValidation` Property (bloc `converter { }`).
- `DocumentExtension.kt` : `+abstract xrefValidation` (mirror flat).
- `DocumentPlugin.kt` : convention OFF, mirror `converter.xrefValidation`, CLI `-Pdocument.xrefValidation`,
  `registerValidateDocumentXref` (tâche `validateDocumentXref`, groupe `document`).
- `ValidateDocumentXrefTask.kt` — NOUVEAU (tâche dédiée rapport JSON).
