== Livrable (cadrage)

Fichier créé : `.agents/CADRAGE_EPIC_DOC_SEMANTIC_TABLE.adoc` — **13 décisions,
6 US ~22 pts**, structuré comme les cadrages maison (contexte, audit, décisions,
US, DAG, DSL, gates, risques, méthode).

Décisions structurantes :

* *D1* périmètre = lifting sémantique des tableaux (non-goals explicites : pas
  de refonte du pivot, pas de génération de contenu).
* *D2* source de vérité = l'AST **réel** (`Asciidoctor.load` +
  `document.findBy { it is Table }`, `gridPosition`/`colspan`/`rowspan`).
* *D3* identification **opt-in par annotation** `[.semantic-<name>]` ou
  `[semantic=<name>]` — rejet motivé de l'heuristique par nombre de colonnes.
* *D4* schéma **injecté par le consommateur** (`SemanticColumnSpec` abstrait) :
  zéro vocabulaire métier dans le plugin public (patron RENAME-8 D14).
* *D5/D6* nouveau domaine pur `document.semantic` + port `SemanticTableReader`
  / adapter `AsciidoctorTableReader` (dependency inversion, le domaine ne
  dépend jamais de `org.asciidoctor.*`).
* *D7* tâche thin `collectTableSemantics` + export `table-semantics.json`.
* *D8* validation des rôles `required` (STRICT/LENIENT/OFF, symétrique xref).
* *D11* `SafeMode` respecté à la lecture ; *D12* `bookPipeline` et le pivot
  inchangés ; *D13* baby-step DDD/TDD/BDD strict.
