:date: 2026-11-05

== Mission

Empêcher qu'une variante traduite perde ou duplique sa structure de blocs
(échec du C6 ciblé : 4 `section-count-drift` introduits sur `en`, `0105`
98 blocs rendus vs 96 attendus).

== Livré

* `TranslatedTextSanitizer` : CR/LF → espace, trim, échappement des marqueurs
  de bloc en tête (`=`, `|`, `[`, `----`, `....`, `++++`) ; appliqué à tous les
  textes traduits (titres, paragraphes, listes, tableaux, admonitions,
  description lists). Les `PivotInline.LineBreak` intentionnels sont préservés.
* Garde structurelle `ContentTranslationService.requireSameBlockStructure` :
  rendu en mémoire, ré-parse, comparaison de signature (count + kind sequence)
  avec la source ; en cas d'écart, `IllegalStateException` et **fichier non
  écrit**. Couvre les 3 chemins d'écriture.
* `DocumentTranslator.structureSignature` partagé (interne) entre le delta et
  la garde.
* Tests : 9 sanitizer + 6 garde (heading avec newline, paragraphe introduisant
  `==`, marqueurs de tête, renderer qui perd/duplique un bloc, write nominal).
* Commit code `61801cf` ; CI `42077356614` **verte** (Unit + BDD + Functional +
  POM + static).
