== Pièges / apprentissages à retenir

. Les types DSL des gardes (`IncludeGuardMode`, `XrefValidationMode`,
  `HtmlLinkLintMode`, `SafeMode`) exigent des *imports explicites* dans le
  `build.gradle.kts` du consommateur — la doc d'utilisation doit les lister
  (pattern identique aux FT TestKit du borough).
. Le knob `outputFileName` est un *système property CLI*
  (`-Pdocument.outputFileName`) — rien à câbler côté consommateur ; le bloc
  `template { outputFileName }` est un knob séparé (traduction DOC-13).
. La preuve négative (STRICT reject) est le vrai test de contrat — le positif
  seul pourrait passer pour de la coïncidence de configuration.
