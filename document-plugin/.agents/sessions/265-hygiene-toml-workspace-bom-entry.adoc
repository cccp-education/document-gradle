== Justification de la garde (défense en profondeur)

La garde est *additive et tolérante* : une entrée absente est un succès (le toml

diverge est un échec. Elle ferme le trou que l'entrée morte exploitait : une
valeur périmée pouvait survivre à chaque bump de pin sans qu'aucune garde ne
la voie. Pattern défensif du `DocumentPluginPublicationTest` (rôle prouvé
