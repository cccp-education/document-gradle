=== 2. Fix parser AsciiDoc — délimiteurs source `....` + titres de bloc (S032b)

Découverts pendant le batch réel (fake mode a reproduit la troncature → bug parser, pas LLM) :

- **Bug 4-dot** : les blocs `[plantuml]` délimités par `....` (au lieu de `----`) n'étaient pas reconnus

- **Bug titres de bloc** : `.Structure HTML initiale` entre `[source,html]` et `----` cassait la détection
  → tout le reste avalé (article 0082 : 373→134 lignes, 7→2 sections). Fix : `isBlockTitleLine` skippé.

Tests : AsciiDocParserTest (+3 : plantuml 4-dot, non-swallowing, source block avec titre).
