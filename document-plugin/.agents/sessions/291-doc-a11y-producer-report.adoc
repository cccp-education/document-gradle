== Objet

La session 223 a cadré `GBL-011` (accessibilité du livrable formation) et livré
côté academy la porte qui **consomme** un `a11y-report.json`. Cette session livre
le **producteur** du rapport côté `document` : les vérifications HTML/EPUB et le
contrat JSON que l'academy lit déjà.

== Livré

- Domaine `document.a11y` : `DocumentA11yReport`, `DeliverableA11yReport`,
  `DocumentA11yFinding`, `DocumentA11yRules`/`DocumentA11ySeverity`.
- `HtmlAccessibilityInspector` : `lang` sur `<html>`, `alt` sur chaque `<img>`
  (`alt=""` accepté), `th` si table, `h1`.
- `EpubAccessibilityInspector` : lecture ZIP tolérante des XHTML + métadonnées
  OPF `schema:accessMode`/`accessibilityFeature`.
- `DocumentA11yAuditor` : HTML/EPUB inspectés, PDF déclaré `pdf-not-tagged` avec
  la limite « PDF non PDF/UA ».
- Tâche `reportDocumentAccessibility` : `build/docs/document/a11y-report.json`,
  advisory par défaut, `-Pdocument.a11yStrict=true` pour échouer sur `ERROR`,
  `mustRunAfter` les conversions (utilisable standalone).
- 5 fichiers de tests : HTML, EPUB (fixture ZIP réelle), rapport, auditeur,
  tâche (ProjectBuilder).

*Contrat consommé par academy* : `deliverables[].kind`,
`findings[].rule/severity/location/message`, `deliverables[].limits`.
