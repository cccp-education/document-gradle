38. *Gate structurel, pas regex* sur la prose OCR (guillemets « → `<<`).
39. *Le corps OCR peut porter une ancre in-band* — gate D1 sur les refs de la TOC.
40. *Fan-out dynamique = `@OutputFiles`, pas `@OutputDirectory`* (S-271/S-272).
41. *Le fake multi-langue suffixe chaque cible, pas la source* (S-271).
42. *Une CI morte en configuration masque toute la dette aval* — corriger les
    barrières **ensemble** (S-273).

    conventions peut **retirer silencieusement** les runners Cucumber de `check` ;
    une CI verte n'est pas une CI couvrante (S-274).

    doit exporter `CCCP_PUBLISH=true` sinon nmcp publie non signé (rejet Central)
    (S-274).

    `ghaction-import-gpg|gpg_private_key` laissait passer « action retirée, input
    gardé » (faux vert). Exiger l'action précisément (S-274).

    au graphe seulement quand `includeSource` est actif (le graphe par défaut
