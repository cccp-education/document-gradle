== Mission session 275

S-274 (2026-09-28) a livré l'**EPIC DOC-CI-ISOLATION US-4** (release gate) :
la CI peut désormais **publier sur Maven Central depuis un tag**. Un job
`publish` (`if: startsWith(github.ref, 'refs/tags/v')`, `needs: [test]`) importe
une clé GPG, matérialise les secrets OSSRH dans `~/.gradle/gradle.properties`,
exporte `CCCP_PUBLISH=true`. Garde pure `document.ci.ReleaseWorkflow` (7 UT + BDD
`@release-gate`, 26e runner). **Secrets configurés** (OSSRH_USERNAME/PASSWORD +
GPG_PRIVATE_KEY/PASSPHRASE).

*Blocage cross-borough levé* : la convention `publishing` désactivait la
signature sous `CI=true` (Central rejette le non-signé) → `SigningPolicy` 3ᵉ
dimension `CCCP_PUBLISH` + `conventions-plugin` **0.0.8** publié Central
(bundle PUBLISHING → repo1 200).

**Découverte P0** : l'adoption conventions 0.0.7 (S-273) avait retiré les **25
runners Cucumber dédiés** de `check` (`additionalTasksInCheck` défaut `false`) —
la CI verte ne couvrait presque rien. Corrigé : `additionalTasksInCheck = true`
→ `check` planifie **27 tâches Cucumber** ; timeout test 20 → 40 min.

Le re-pin catalogue ws **0.0.59** (piège #13, MEMPHIS `6aa2387`) a été fait au
passage.

**Preuve finale** : CI **VERTE** — run `36466896278` (commit `afc5829`), job
Build & Test `success` 27m45s (24+ tâches Cucumber dont `:releaseGateCucumberTest`),
job Publish correctement SKIPPED (pas de tag). Le 1er run (`36463649717`) avait
révélé un faux vert de la garde GPG (corrigé, piège #45).
