3. *Chaîne N3 staged* : produce → validate → collect (3 builds).

5. *Dérivation knob sans dépendance de tâche* : jamais provider vers

== Anti-glue Cucumber (règle de propriété — S-238)

Chaque feature a UN runner propriétaire. Le runner global (glue
`document.scenarios`) ne découvre que `document.feature` +
`release-notes.feature` + `frontmatter_retranslate.feature`. Toute nouvelle
feature doit soit rejoindre un runner dédié (runner + glue + tag +
CucumberTaskSpec dans build.gradle.kts), soit explicitement rejoindre le global
avec ses steps dans `document.scenarios`. Le 22e runner dédié est
`bookNavigationCucumberTest` (S-262).
