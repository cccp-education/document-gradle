== Anti-glue Cucumber (règle de propriété — S-238)

Chaque feature a UN runner propriétaire. Le runner global (glue
`document.scenarios`) ne découvre que `document.feature` + `release-notes.feature`
+ `frontmatter_retranslate.feature`. Toute nouvelle feature doit soit rejoindre un
runner dédié (runner + glue + tag + CucumberTaskSpec), soit explicitement
rejoindre le global. Le 22e runner dédié est `bookNavigationCucumberTest` (S-262).
La BDD `@book-translate` (US-4) sera le **23e runner**.
