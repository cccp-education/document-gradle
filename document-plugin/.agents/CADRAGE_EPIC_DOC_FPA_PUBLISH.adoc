== Contexte

Arbitrage pilote (2026-09-07) : priorité critical path MVP0. Document est
le maillon WRITE + PUBLISH de la chaîne GBL-003. Constat structurant :
le livre FPA navigable est DÉJÀ publié multi-format (S-082 : livre.adoc
+ livre.html/pdf/epub + book-ocr-issues.json via assembleBook/bookPipeline).

== Constats

1. S-082 a livré le livre complet navigable via document-gradle (bump
   0.0.15, dogfooding TDD-validé sur le corpus FPA complet 203 pages).
   Le plugin est depuis passé 0.0.16 Central (S-249, 6 gardes distribuées).
2. L'EPIC DOC-BOOK-VALIDATE est en cours (VALIDATE-1/2/3 ✅ S-078, reste
   ~6 pts) et FPA-BOOK-6-5 (itération humaine OCR 16 pages) est le P0
   côté Tombouctou. Ces travaux AMÉLIORENT le corpus — la republication
   document en profite automatiquement.
3. GBL-003.6 est donc un *vérifier de drift* optionnel : quand le corpus
   est corrigé (post OCR humain), relancer assembleBook + bookPipeline
   avec la version courante 0.0.16. Zéro feature nouvelle attendue.
4. Frontière licence (S-070) : le livre est une œuvre dérivée — les
   artefacts publiés restent dans office/ ou derrière arbitrage pilote
   pour une diffusion publique.

== Décisions
